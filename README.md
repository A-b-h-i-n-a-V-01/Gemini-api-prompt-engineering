# Prompt Engineering and Gemini API Fundamentals

## Overview

This project explores Google's Gemini API and demonstrates various prompt engineering techniques using Python.

The notebook covers prompt design, role prompting, system instructions, structured JSON output generation, generation parameter tuning, and interactive chatbot development using Gemini 2.5 Flash.

---

## Features

* Gemini API Integration
* Basic Prompt Engineering
* Role Prompting
* System Instructions
* Structured JSON Output
* Generation Parameter Tuning
* Interactive Chatbot Development

---

## Project Workflow

1. Configure Gemini API
2. Initialize Gemini 2.5 Flash Model
3. Generate responses using basic prompts
4. Apply role-based prompting
5. Experiment with system instructions
6. Generate structured JSON outputs
7. Compare different generation configurations
8. Build an interactive chatbot

---

## Generation Configurations

* Low creativity

* High creativity
* More expressive responses
